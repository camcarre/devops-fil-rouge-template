```markdown
# Déploiement Kubernetes — Forum DevOps

## Prérequis
- minikube ≥ 1.30, kubectl, Docker Desktop actif

## Démarrage du cluster

```bash
minikube start --profile forum --addons ingress,metrics-server
minikube profile forum
```

## Déploiement de l'application

```bash
# Appliquer tous les manifests (namespace, config, secrets, DB, API, ingress)
kubectl apply -f k8s/ -n forum

# Vérifier que les pods sont Running
kubectl get pods -n forum
```

## Accès à l'API

```bash
# Option 1 — port-forward direct
kubectl port-forward svc/api 8000:8000 -n forum

# Option 2 — minikube tunnel + /etc/hosts forum.local → 127.0.0.1
minikube tunnel --profile forum
```

## Monitoring (Prometheus + Grafana)

```bash
# Port-forward Prometheus
kubectl port-forward svc/prometheus 9090:9090 -n forum

# Port-forward Grafana
kubectl port-forward svc/grafana 3000:3000 -n forum
# Grafana : http://localhost:3000 (admin/admin par défaut)
```

## Vérification rapide

```bash
curl http://localhost:8000/healthz
curl http://localhost:8000/metrics
```
