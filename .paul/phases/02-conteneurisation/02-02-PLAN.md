## AC-2: Auth register/login fonctionnel
```gherkin
Given l'app démarre
When POST /auth/register avec {username, email, password} valide
Then 201 retourné, utilisateur créé en DB, password_hash stocké (jamais le mot de passe en clair)

When POST /auth/login avec {email, password} corrects
Then 200 retourné avec {"access_token": "...", "token_type": "bearer"}

When POST /auth/login avec mauvais mot de passe
Then 401 retourné
```

## AC-3: Routes CRUD forum protégées
```gherkin
Given un token JWT valide obtenu via /auth/login
When GET /categories
Then 200 + liste des catégories

When POST /categories avec Authorization: Bearer <token>
Then 201 + catégorie créée

When GET /categories/{id}/topics, POST /categories/{id}/topics
Then réponses correctes (200/201)

When GET /topics/{id}/posts, POST /topics/{id}/posts
Then réponses correctes (200/201)

When requête sans token sur route protégée
Then 401 retourné
```

```gherkin
Given tous les fichiers créés
When git diff avant commit
Then SECRET_KEY et DATABASE_URL uniquement via os.getenv — aucune valeur réelle
```

<task type="auto">
  <name>Task 2: Router auth (register + login)</name>
  <files>src/routers/auth.py</files>
  <action>
    src/routers/auth.py — router = APIRouter(prefix="/auth", tags=["auth"]) :

    POST /register :
    - Body : UserCreate
    - Vérifier email unique → 400 si déjà pris
    - Hasher le mot de passe via hash_password()
    - Créer User en DB, commit, refresh
    - Retourner UserOut avec status_code=201
    Ne jamais stocker le mot de passe en clair.

    POST /login :
    - Body : OAuth2PasswordRequestForm (username = email)
    - Chercher User par email → 401 si absent
    - verify_password() → 401 si invalide
    - create_access_token({"sub": str(user.id)})
    - Retourner Token

    Dépendance get_db() via Depends(get_db).
  </action>
