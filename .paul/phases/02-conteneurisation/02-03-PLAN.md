<tasks>

<task type="auto">
  <name>Task 1: Dockerfile multi-stage + .dockerignore</name>
  <files>Dockerfile, .dockerignore</files>
  <action>
    Dockerfile — deux stages :

    Stage 1 (builder) :
    - FROM python:3.12-slim AS builder
    - WORKDIR /app
    - Copier requirements.txt
    - RUN pip install --no-cache-dir --prefix=/install -r requirements.txt
    Ne pas installer en global — prefix /install permet de copier uniquement les dépendances dans le runtime.

    Stage 2 (runtime) :
    - FROM python:3.12-slim AS runtime
    - WORKDIR /app
    - Copier /install depuis builder vers /usr/local
    - Copier src/ et alembic/ et alembic.ini
    - Déclarer ENV DATABASE_URL="" SECRET_KEY="" PORT=8000 — sans valeur réelle
    - EXPOSE ${PORT}
    - CMD ["sh", "-c", "uvicorn src.main:app --host 0.0.0.0 --port ${PORT}"]
    Utiliser sh -c pour permettre la substitution de variable d'env dans CMD.
    Ne jamais hardcoder DATABASE_URL ou SECRET_KEY — valeurs vides par défaut.
    Ne pas copier .env, .git, __pycache__, .venv dans l'image.

    .dockerignore :
    .env
    *.env
    .git
    .gitignore
    __pycache__
    *.pyc
    *.pyo
    .venv
    venv
    .paul
    docs
    README.md
    *.md
  </action>
  <verify>docker build -t forum-api . 2>&1 | tail -5</verify>
  <done>AC-1 satisfait : `docker build -t forum-api .` exit 0, image présente dans `docker images forum-api`</done>
</task>
